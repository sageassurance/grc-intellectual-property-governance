# Alderline Civic Systems | Vendor cybersecurity assurance

**Portfolio author** Cierra Jennings

Alderline Civic Systems is a fictional govtech provider operating a municipal permit and service request portal. The exercise follows resident data from vendor intake through contract review, control assessment, and corrective action.

| Deliverable | What it shows |
|---|---|
| [Cybersecurity GRC workbook](alderline-govtech-cybersecurity-grc.xlsx) | Four vendor reviews, six selected NIST CSF 2.0 current-to-target assessments, five corrective actions, and a policy rollout tracker |
| [Third-Party Data Protection Policy](alderline-third-party-data-protection-policy.md) | Plain-language requirements for vendor approval, monitoring, incident reporting, exceptions and offboarding |

Start with **Start Here** in the workbook. Follow vendor, evidence and finding IDs across the tabs to see how each issue becomes a corrective action with an owner, deadline and independent verification criteria.

The organizations, evidence records, ratings, findings and schedules are fictional. The scoring rubric is for this exercise. It uses selected outcomes from the [NIST CSF 2.0 Core](https://doi.org/10.6028/NIST.CSWP.29) and follows NIST’s [Current and Target Profile guidance](https://csrc.nist.gov/pubs/sp/1301/final).
